What the analyzer does

Designed as a small, understandable Python project for learning and boot-log triage.

⌕

Reads Android logs

Accepts plain-text dmesg and logcat output and keeps the original line numbers for review.

◉

Flags and classifies issues

Uses readable rules to identify severity and group common kernel, driver, firmware, SELinux, init, and framework errors.

◷

Checks boot timing

Estimates the timestamp span and highlights initialization actions with long reported durations.

▤

Builds reports

Creates HTML and JSON reports with issue counts, slow stages, and practical recommendations.

⌘

Includes test cases

Three automated tests cover issue classification, slow-stage detection, and missing timestamps.

↗

Works with ADB captures

The README explains how to collect dmesg and logcat files from an emulator or development device.
